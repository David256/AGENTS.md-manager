# AGENTS.md manager

```bash
python3 main.py
```

Add the template file in the `./template` folder.

Use tags like `<!-- @name-here -->` in the markdown files.

Add the same `name-here.md` files in the `./resources` folder.

This script will watch for changes in both folders and will generate a new file
in the `./generated` folder.
